# 데이터 & 텍스트 변환기

## 설명

**데이터 & 텍스트 변환기**는 다양한 데이터 형식 변환 및 텍스트 조작 작업을 위한 다용도 웹 애플리케이션입니다. JSON, YAML, XML 간의 변환, Base64 인코딩/디코딩, URL 인코딩/디코딩, HTML 엔티티 처리, Unix 타임스탬프와 날짜/시간 변환, 색상 코드 변환, 텍스트 서식 지정 (들여쓰기, 축소, 줄 정렬 등), 대소문자 변경, 텍스트 카운팅, 정규식 테스트 및 대체 등 광범위한 기능을 제공합니다.

사용자 편의를 위해 심플한 인터페이스, 작업 기록, 클립보드 내용 기반 도구 제안, 다크 모드/라이트 모드 테마 전환 등의 기능을 지원합니다.

라이브 데모 : https://sigco3111.github.io/ConvertFormat/

[![Live Demo](https://img.shields.io/badge/Live_Demo-GitHub_Pages-222222?style=for-the-badge&logo=githubpages&logoColor=white)](https://sigco3111.github.io/ConvertFormat/)

## 주요 기능

*   **다양한 변환 도구**: 다양한 데이터 및 텍스트 처리 요구사항을 충족하는 포괄적인 도구 모음.
*   **단일 작업 인터페이스**: 깔끔한 인터페이스로 한 가지 변환 작업에 집중할 수 있습니다.
*   **작업 기록**: 최근 변환 내역을 저장하고 쉽게 다시 불러올 수 있습니다 (최대 50개 항목).
*   **클립보드 기반 제안**: 클립보드에 복사된 내용을 분석하여 적합한 도구를 추천합니다.
*   **테마 지원**: 사용자의 선호에 따라 라이트 모드와 다크 모드를 선택할 수 있습니다.
*   **반응형 디자인**: 데스크톱 및 모바일 장치에서 원활하게 작동합니다.
*   **실시간 변환**: 많은 도구에서 입력 시 실시간으로 결과를 업데이트합니다.
*   **입력/출력 관리**: 입력 및 출력 내용을 쉽게 복사, 지우기, 상호 교환할 수 있습니다.
*   **오프라인 지원**: 기본적인 기능은 인터넷 연결 없이도 작동합니다 (CDN 로딩 후).

## 사용 가능한 도구

### 데이터 변환
*   **JSON <> YAML**: JSON과 YAML 형식 간에 변환합니다.
*   **JSON <> XML**: XML과 JSON 형식 간에 변환합니다.

### 웹 유틸리티
*   **Base64 인코더/디코더**: Base64로 인코딩하거나 디코딩합니다.
*   **URL 인코더/디코더**: URL 구성 요소를 인코딩하거나 디코딩합니다.
*   **HTML 엔티티 인코더/디코더**: HTML 엔티티를 인코딩/디코딩합니다.

### 개발자 유틸리티
*   **타임스탬프 <> 날짜/시간**: Unix 타임스탬프를 사람이 읽을 수 있는 날짜로 또는 그 반대로 변환합니다.
*   **색상 변환기**: Hex, RGB, HSL 색상 코드 간에 변환합니다.

### 텍스트 조작
*   **텍스트 포맷터**: 텍스트 서식 지정 (들여쓰기, 축소, 줄 정렬, 중복 제거 등).
*   **대소문자 변환기**: 텍스트 대소문자 변경 (대문자, 소문자, 제목 형식 등).
*   **카운터**: 문자, 단어, 줄, 바이트 수를 계산합니다.
*   **정규식 테스터/리플레이서**: 정규식을 테스트하고 텍스트 대체를 수행합니다.

## 기술 스택

*   **프론트엔드**: React, TypeScript
*   **스타일링**: Tailwind CSS
*   **아이콘**: Font Awesome
*   **외부 라이브러리**:
    *   `js-yaml`: YAML 처리
    *   `xml-js`: XML 처리
    *   `date-fns`: 날짜/시간 처리

## 사용 방법

1.  저장소를 클론합니다:
    ```
    git clone https://github.com/your-username/data-text-converter.git
    cd data-text-converter
    ```

2.  의존성을 설치합니다:
    ```
    npm install
    ```

3.  개발 서버를 실행합니다:
    ```
    npm run dev
    ```

4.  빌드 (배포용):
    ```
    npm run build
    ```
